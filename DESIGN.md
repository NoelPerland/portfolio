# Portfolio design

- Role: exhibition of Noel's real work. Projects, portrait, CV and verified engineering details supply the evidence.
- Voice: direct, specific, first person. Name built systems and constraints; no generic claims or invented results.
- Type: Archivo Black for exhibition titles, Space Grotesk for reading, IBM Plex Mono only for useful identifiers.
- Color: plum ink, paper, lavender. Project previews keep their own product colors; portfolio never borrows one app's identity.
- Layout: generous page margins and one large preview at a time. The preview opens the live site, or source when no deployment exists.
- Motion: only gallery state and direct hover/focus feedback; honor reduced motion.
- Check: six projects in established order; keyboard and touch gallery, readable themes, accurate links and screenshots.
